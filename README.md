# Meu Bolso

App pessoal de finanças feito pra usar no iPhone como web app.

- **Hoje:** quanto dá pra gastar no dia, somando o que sobrou dos dias anteriores
- **Renda:** salário e renda extra, mais o backup dos dados
- **Contas:** contas fixas (todo mês), contas só do mês e parceladas
- **Cartões:** fatura de cada cartão, com vencimento e fechamento
- **Meta:** quanto guardar por mês pra chegar no objetivo

Os dados ficam salvos só no próprio celular (localStorage). Use "Copiar backup" de vez em quando.

## Instalar no iPhone
1. Abra o link do GitHub Pages no Safari
2. Toque em Compartilhar → Adicionar à Tela de Início
